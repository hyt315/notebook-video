# 草稿纸讲解：出现规则、设计规范与动效

**第一原则**：画面像一张边讲边写的草稿纸，画面上没有笔。每样东西在旁白讲到它时才出现、一点点长出来；同一时刻不冒出一堆。「画什么」和「什么时候出现」冲突时，以草稿纸讲解为准。

<a id="reveal-rules"></a>
## 1. 出现规则（草稿纸核心）

`auto` 路线由引擎自动满足；手写场景必须严格照做：

1. **跟着旁白**：元素只在旁白讲到它的那一句开始时出现，绝不提前剧透（`validate-presentation.py` 拦截早于所属 cue 超过 `BEAT_SPOILER_FRAMES` = 12 帧，或晚于句末超过 `BEAT_LATE_FRAMES` = 8 帧的节拍）。
2. **长出来（`GROW`）**：
   - 文字与卡片左→右展开：字数 × `4` 帧，钳在 `12–45` 帧（`contract.json` 的 `GROW`）；代码行每字 `1.5` 帧、上限 `24` 帧。
   - 线稿按部位描出 `24–45` 帧；圈注/下划线/箭头 `12` 帧，手写小字引线 `8` 帧 + 每字 `2.2` 帧（`ANNOT`）。
   - 手账页真图版可整件贴上，但同样要等旁白讲到它才出现。
3. **不扎堆**：同一镜相邻两样元素开始出现至少间隔 `12` 帧；同一时刻最多 `2` 样在生长（窗口内 ≥3 个 beat 触发聚簇预警）。
4. **不预铺**：切镜时纸面上只保留已讲过的内容；开镜前 `6` 帧内最多 `1` 样元素开始出现。

<a id="draftpaper-design"></a>
## 2. 草稿纸设计规范

- **亮底纸面 + 深墨文字**：保证正文对比度 ≥ `4.5:1`，避免深色背景配霓虹发光线。
- **每镜字号 ≤ 3 档**：标题、正文、标注拉开层级；auto 路线正文地板 `MIN_FONT`（32px），安全行高 `SAFE_LH`（1.42），代码绝对字号地板 `MIN_LABEL_FONT`（13px）。
- **每镜画面文字预算**：不含字幕不超过 `SCREEN_READ_BUDGET`（40 加权字），把长句子留给旁白，纸面只写关键词、数字和结构关系。
- **停顿与呼吸**：句间留出呼吸空隙，关键结论或锤子句后留 1.5–2.5 秒不塞新元素，但成片连续静止不得超过 `DEFAULT_MAX_STATIC`（2.5s，锤子镜 `HAMMER_MAX_STATIC` = 3.0s）。

<a id="motion-design"></a>
## 3. 动效契约

- **纯帧驱动**：一切动画由当前帧 `f`（或 `frame`）经确定性插值算出，禁止 CSS `transition`、`requestAnimationFrame`、`Math.random()`。
- **合法入场闭集**：`build`、`fade`、`rise`、`slide`、`zoom`（禁止弹性弹跳 `pop`，由 `validate-composition.py` 判 P0）。
- **动效与改错细节**：滚动数字须用 `tabular-nums` + 固定小数位防抖，进度条动 `scaleX` 不动 `width`，不过冲回弹；改错保留灰字删除线并在旁写正值；画面强调色面积 ≤15%，不与当句字幕逐字重复。
- **单一主运动**：同一时刻画面里只有一个主视觉焦点在推进或运镜，避免多处同时闪烁分散注意力。
- **空间密度**：动画前先在 1920×1080 设计舞台上划好工作区，大物件各有固定的家，中央走廊只留给传递；宁可 3–5 个大的语义物件，不要 8–12 个小装饰。画面挤了就放大物件重新分布，不要整体缩小。下一组出现前，讲完的物件要移走、盖住或完全离场。
- **连续流程用一张任务卡**：旁白讲一件事走过几个步骤时，保留同一张卡沿可见路径移动，在每一站改标签、颜色或状态，不要每步换一张新卡。
- **克制**：不是每个物件都上每种效果。动态阴影要有真实抬起，数据脉冲要有真实传递，音效要有可见动作，固定的面板保持不动。
- **时长参考**：30 秒 5–7 个场景；60 秒 3–4 幕；2–3 分钟 8–12 段、每段 10–20 秒。比喻换了就干净切，同一概念展开时就继续在原画面上长。

## 4. 画面质感纪律（质感服务于「看得清」）

1. **三层层次分离（反一片死平白板）**：底面（纸纹/底色）、主体层（图版/组件与轻投影）、强调层（批注/印章/高亮）明暗与轮廓清晰分离；亮部不过曝、暗部不糊，绝不用模糊/虚焦/花哨转场硬凑「电影感」。
2. **跨镜主物件延续（反 PPT 翻页感）**：相邻镜讲同一原理的不同侧面时，保留核心锚点物件（同一图版、柱条或代码）通过推近、加注或变色推进，而非每切一镜清屏重来。
3. **景别与视觉权重交替**：高密镜（`code`/`flow`/`compare`）与低密呼吸镜（`number`/`type`/锤子帧）交替，全景交代关系、特写/放大镜看清细节，禁止单一远景或满屏卡片连排到底。
4. **聚光压暗与先见其物**：复杂结构用 `{{关键词|元素id}}` 聚光弱化非焦点层；反常现象或核心对比开镜即落定主体，不让画面比旁白慢半拍。
