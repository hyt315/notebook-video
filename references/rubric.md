# 「讲清楚」与精品品质评审卡

本评审卡共 **5 项**，每项 **1–5 分**（任一项 `< 4` 建议先修改再渲染）。键名固定如下，供 `validate-treatment.py` 与 `renders/report.md` 首屏读取：

```json
{"review": {"rounds": [{"scores": {"复述核心概念": 4, "先打掉常见误解": 4, "专属例子或隐喻": 5, "画面时机帮助理解": 4, "记住的锤子句": 5}}]}}
```

- **评审分工与成本控制**：常规组件视频优先自查 `renders/report.md` 首屏成片摘要（镜数、运镜意图数、转场、分辨率与门禁 P0/P1）；手作皮肤（`journal` / `papercut` / `archive`）及重要作品在 `--render` 前开独立新会话（仅给 `--stills` 联系表、`storyboard.md` 与 `treatment.json`）盲评并回写 `review.rounds`。

## 1. 复述核心概念（高信息增量 · 不超载 · 有完整性）

- **1–2 分**：名词堆砌或主线涣散，讲完说不清核心机制；或单镜塞满细节让观众认知过载。
- **3 分**：大意清楚但因果缺环，或夹带无关旁枝背景。
- **4 分**：只讲清一件事，无多余冗余，观众能准确复述机制。
- **5 分**：高信息增量且克制平衡，单看核心几镜即懂因果全貌，首尾完整闭合。

## 2. 先打掉常见误解（反直觉开场 · 拒绝标题党与假悬念）

- **1–2 分**：教科书平铺「XX 是一种……」开场；或卖关子/标题党拖到片尾仍不给实质答案。
- **3 分**：有疑问或对比，但开头不够尖锐，前 3–6 秒未立住张力。
- **4 分**：前 3–6 秒用强事实、直观反差或诚实问题抓住注意力，随后续镜头拆穿直觉误区。
- **5 分**：开场即给出无法忽视的反常识冲击并直奔核心矛盾，机制揭晓不拖泥带水，带来清晰「原来如此」。

## 3. 专属例子或隐喻（高辨识 · 反跨片同质化）

- **1–2 分**：泛泛空称（「某系统」「性能提升」），或不同选题长得像同一模板/同一布局节奏复制粘贴。
- **3 分**：有具体数字或案例，但视觉隐喻与表达仍偏通用。
- **4 分**：例子具体到可感知数字/真实图版/场景，版式与视角随题材区分开。
- **5 分**：案例、图版或手作原生动作具有强排他性（换相邻题材立刻不成立），兼具新鲜度与跨片识别度。

## 4. 画面时机帮助理解（多景别推演 · 非幻灯片）

- **1–2 分**：静态大图配大段文字、PPT 贴卡片或模板轮播，画面停滞或脱离旁白。
- **3 分**：元素大致跟上台词，但镜头语言单一（全程同向推近或固定景别）。
- **4 分**：讲到哪长到哪，推近/拉远/横移与特写镜头呼应讲解重心，常驻遮挡克制（≤5%）、音画同步自然。
- **5 分**：多景别调度、关键词聚光、留白节奏与稀疏拟音共同替观众卸载认知负荷，关掉声音仍能读懂推进逻辑。

## 5. 有一句能记住的锤子句（收束闭合 · 有效记忆点）

- **1–2 分**：结尾泛泛升华或突然切断，无明确收束。
- **3 分**：结论清晰但偏长，缺少对比张力或未回应开场提问。
- **4 分**：有短促有据的核心结论句，直接闭合第 1 镜疑问。
- **5 分**：出现 ≤16 字过耳不忘的锤子句，精准压缩全片原理并与开场画面形成回扣，自然留白收尾。
