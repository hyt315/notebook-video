# Dependency and asset policy

Notebook Video keeps source downloads small and reproducible by separating manifests, installed dependencies and runtime assets.

| Item | Stored in Git | Local behavior | Reason |
| --- | --- | --- | --- |
| `package.json`, `package-lock.json` | Yes | `npm ci` installs exact versions when `prepare-browser` or `render` first runs | Reproducible dependency graph |
| `node_modules` | No | Downloaded locally and reusable between renders | Generated, platform-dependent and large |
| Remotion rendering browser | No | `prepare-browser` downloads it once when needed | Platform-dependent binary |
| Full Chromium for the page-turn transition (3.3.0, optional) | No | Found in `NOTEBOOK_VIDEO_FX_BROWSER` or the local Playwright cache (`npx playwright install chromium`); a pixel probe decides whether to use it; missing → `pageturn` / `peel` fall back to `slide` / `drop` with a P1 note | Chrome Headless Shell has no WebGPU adapter; see `references/fx-effects.md` |
| TTS client or model | No | Selected and connected externally by the user or agent | Provider-neutral; avoids unnecessary SDKs and credentials |
| edge-tts (Python, LGPL-3.0) | No | Detected at run time by `scripts/tts.py`; `pip install edge-tts` to enable. Calls Microsoft's online speech service (network required) | Default TTS engine since 3.5.0; not redistributed, so the LGPL obligations stay with the user's own install |
| Generated narration | No | Supplied or generated by the user before `sync` | Voice and redistribution rights vary by provider |
| Image-generation client or model | No | Selected from the current agent/platform when available | Provider-neutral; Codex enhancement is optional |
| Official generated illustration | Yes | Copied into the editable project and tracked in `visual-assets.json` | Demonstrates image-plus-text composition; source, crop, hash and rights note are recorded |
| LXGW WenKai Lite (Regular/Medium) | Yes | Copied into each editable project | Unified CJK typeface; SIL OFL 1.1 notice in assets/fonts/ |
| Clash Display / Space Grotesk (Tibo-Please) | Yes | Copied into each editable project | Latin accents; Fontshare/Google OFL free-commercial fonts |
| Noto Serif SC Bold (craft skins) | No | `fonts --serif` / `new-project --style=journal\|papercut\|archive` downloads Serif2.003 from notofonts/noto-cjk and checks sha256 | ~12 MB OTF; OFL-1.1 text is committed in `assets/fonts/` |
| Craft foley (Kenney RPG Audio, CC0) | Yes (6 small OGG) | Copied with the template | Recorded paper / blade / stamp sounds for the craft skins; source per file in `sfx-manifest.json` |
| Craft paper tiles and craft-skin backgrounds | Yes | Copied with the template | Code-generated by `scripts/dev/make-craft-textures.py` (fixed seed), sha256 in manifests |
| Background library (3.3.0, 34 WebP, ~2.7 MB) | Yes | Copied with the template | Light backgrounds per skin; Paper Shaders pre-renders, PD / CC0 Commons textures and fixed-seed drawings; source, licence, sha256 and contrast metrics in `manifests/backgrounds.json` |
| Wikimedia Commons / Openverse media | No | `commons-search.py add` downloads into the user's project with licence + credit | Third-party works stay with their own licences; never committed to the skill |
| RapidOCR (optional) | No | `pip install rapidocr onnxruntime` enables `validate-ocr.py`; missing → the check is skipped with a hint | Apache-2.0; ~20 MB of models, not needed by CI |
| Procedural WAV effects | Yes | Copied with the template | Small deterministic runtime assets with a reuse notice |
| Renders, caches and temporary files | No | Created locally and excluded from ZIP packages | Outputs are not source dependencies |

Do not commit installed packages, downloaded browsers or unused image generations. Update JavaScript dependencies by changing the manifest and lockfile together, run `npm audit`, then run the complete validators. Remotion and any image/TTS provider remain governed by their own terms regardless of how they are connected.
