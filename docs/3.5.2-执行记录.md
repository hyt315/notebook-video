## 5. 已知不足

**模板生长比 S7 = 0.56，未达计划要求的每镜 ≥0.60。**

八镜实测：`0.89 / 0.70 / 0.83 / 0.80 / 0.85 / 0.68 / 0.56 / 0.78`，中位 **0.80**（目标 ≥0.80 达成），
S2 0.61→**0.70**、S6 0.64→**0.68**（目标 ≥0.65 均达成）。

S7 未达标的原因：它的 `beats` 是 `[0, 100, 116]`，第一个节拍就在第 0 帧，按「绑词」规则取景框和
第一条对话必须开镜即在。计划给的退路「把 `ZoomStage` 外框也绑到 `at(0) - 8`」算出来是 `-8`，
等于开镜就在，实测 G 从 0.54 只到 0.56（这点提升来自 `SkeletonCard` 绑到 `at(0, 80)`），
再绑外框没有任何变化，已撤回这段无效代码。

这是「绑词」与「生长比」在「开镜即正文」镜头上的固有冲突，不在 3.5.2 强行凑数，留到 3.6 的版面门禁一起解决。

## 6. 过程中发现并修掉的真缺陷

1. **`_cap` 变量遮蔽**（T-P1-05 引入、R0 抓到）：局部变量取名 `_cap`，让 Python 把整个 `build()`
   里的 `_cap` 当局部变量，第 604 行 `_cap.CHAR_MS` 抛 `UnboundLocalError`——带 `{{术语}}` 的样例
   直接 compose 失败。改名 `_cap_max`。
2. **`sketch.id` 缺失**（T-P0-04 的样例 JSON）：见第 3 节第 3 条。
3. **`.silent-placeholder` 被误入库**：验证时对模板跑过 `preview`，产物写进 `assets/lecture-template/audio/`。
   已删并加进 `.gitignore`（该文件会让 `--render` 以为旁白是静音占位而拒绝出片）。
4. **plan 给的 list-icons 样例过不了 OverlapGate**（R2 的 preview 抓到）：@255「"书脊"被 "DIV" 遮挡」——
   清单面板的容器盖住了线稿的部位标签，跟 `place` 改成 `corner` 无关。按计划只改样例：
   第 2 镜去掉 `point`；与 S4 撞「同图同局部同动作」后，S4 补 `recallOf=S2` 且 label 改「三样」。

## 7. 环境备注

- 临时工程里 `npm ci` 偶发 `npm error Exit handler never called!`（npm 自身 bug），会留下半装的
  `node_modules`（`@remotion/cli/remotion-cli.js` 缺失），之后每次渲染都重试并再崩。
  绕法：清掉 `node_modules` 与 `.tools/npm-cache`；或用已有的同名依赖做目录联接（`New-Item -ItemType Junction`）。
- 渲染一律 `REMOTION_CONCURRENCY=1`、一次只跑一个。
