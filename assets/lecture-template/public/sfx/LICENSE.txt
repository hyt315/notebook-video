SFX library (lib/*.ogg) — CC0-1.0 / public domain dedication.

Every one-shot in lib/ except the six 3.3.0 craft foley files below was rendered in code by earshot forge 0.2.0 recipes
(https://github.com/Leonxlnx/earshot, MIT): physical/modal synthesis, filtered noise and a
computed room. No recorded or sampled third-party audio is contained in any file.
lib/bed.ogg is an additive sine pad generated by scripts/dev/build-sfx-library.py.

To the extent possible under law, the notebook-video authors waive all copyright and related
rights in these generated audio files (https://creativecommons.org/publicdomain/zero/1.0/).
Per-file hashes, durations, loudness, source recipe and intended use: sfx-manifest.json.
Rebuild (maintainers only, needs earshot): python scripts/dev/build-sfx-library.py

3.3.0 craft foley — lib/page.ogg, place.ogg, snip.ogg, stamp.ogg, rustle.ogg, latch.ogg — are trimmed,
loudness-normalised edits of recorded samples from Kenney "RPG Audio" by Kenney Vleugels
(https://kenney.nl/assets/rpg-audio), released under CC0 1.0
(http://creativecommons.org/publicdomain/zero/1.0/). Credit is not required; we give it anyway.
Source file per event: sfx-manifest.json → source. Re-import: python scripts/dev/import-craft-sfx.py <kenney_rpg-audio>
