# 分镜：GitHub 三部曲 · 先导片（EP0）

画面由代码绘制；主题背景可含已登记位图。原生 30fps，约 38.27 秒，最后一句后留 21 帧。准确起止帧以 `manifests/asset-manifest.json` 为准，字幕以实测或已说明精度的语音时间数据为准。

| 章节 | 核心问题 | 主动作 | 衔接与节奏 |
|---|---|---|---|
| 代码不再孤独 | 本地代码如何参与协作？ | 本地硬盘 → 地球与仓库节点建立联系 | 从整体协作网络进入一个实际改动 |
| 第一步 · 参与 | 改动如何成为 PR？ | 同一个任务沿真实 SVG 分支路径移动，到达汇合点后显示 PR | 保留“项目”概念，切入自己的作品 |
| 发布与运营 | 作品如何成为持续维护的项目？ | README/LICENSE/CI 就位，维护仪表与版本发生变化 | 从实际过程归纳三个技能 |
| 三个 AI 技能 | 下一步怎么开始？ | 技能入场，在“智能体陪你走完全程”处依次激活协助状态；结尾退出技能卡，只保留 CTA | 不把所有信息堆在最后一帧；CTA 和字幕有完整尾部留白时间 |

场景、章节 chrome 和局部帧读取同一份场景窗口。相邻镜头正常使用干净切换，不先把整幅内容淡成空纸。镜头微调遵循各画布中心的约束；字幕和 chrome 不随场景镜头移动。

替换内容后，应更新动作 cue、音效、镜头 keyframes 和 review beats。仅修改总时长不能保证新台词与旧动作语义一致。
